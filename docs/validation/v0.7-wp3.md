The frame takes up no tile space. The canvas, placement preview and deposit badges all use the same inner rectangle. This preserves 44 logical pixels per tile and the 528 × 528 CSS-pixel desktop canvas. Compact views fit the whole existing map. Pixi backing resolution scales independently from pointer coordinates. Grid colors, atlas frames, cargo positions and conveyor join artwork match the released board.

The placement preview uses the same read-only checks as the construction command. Moving over a tile does not place an entity or spend credits. A solid outline identifies selection, open corners identify drag rotation, a second arrowhead marks the preferred splitter outlet, and an exclamation mark identifies blocked cargo. Exposed deposits keep their resource glyphs. An unrelated structure on a copper or silicon deposit shows a small corner label and Inspector details. A matching extractor needs no covered-deposit label.

## Verification

| Acceptance boundary | Evidence |

| Exact target and rejection | Browser checks all four frame edges, the first real tile division, a center tile and the last corner at 1280 × 720, 430 × 860 and 1024 × 576. | Gestures | Browser checks actual capture loss, release over a border, valid release one CSS pixel inside, Escape and pointer cancellation. Existing tests cover one press to place and rotate, existing-entity rotation, and reload. |
| Overlays and cargo | Browser checks the two placement symbols and reason labels, all four splitter directions, forward/clockwise/alternating priority, selection and rotation outlines, exposed vs. covered minerals, blocked and absent cargo, distinct ore/metal textures, and track joins during rotation. The blocked splitter case checks that the warning leaves the outlet arrows and covered-deposit badge clear. |
| Fallback and sizing | The atlas-failure case exercises the glyph renderer using the same surface. The existing HUD suite verifies full compact fit and a native 528 × 528 CSS-pixel desktop canvas. |
| Live paid layout | The Corporate M15 browser test reaches the paid scene at 1×, observes the deliberately blocked gear conveyor, then advances two ticks in one second at 2× and checks the same visible map and blockage. |

RED reproduced purchases on the frame, the missing validity preview, and a warning that overlapped a north splitter arrow. Review the cues in a congested factory at both speeds before Product Owner acceptance. The captures above are automated browser observations.
