## 3. Comment 2 — long-press drag rotation

[Owner comment](https://github.com/dzon2000/sector-nine/pull/8#issuecomment-6893397718). Root cause: `Board.onPointerDown/onPointerMove/onPointerUp` and `App.directRotate` originally gated direct gesture on `tool === "select"`. Construction selection prevented long-press rotation of existing objects; the UI did not explain this.

Remediation: an existing nonterminal structure can receive a >12-CSS-pixel press-drag with **any construction tool selected**, unless explicitly in Demolish mode. The command applies exactly one absolute facing change. Short clicks still use the currently selected construction/inspection tool; same-facing gesture remains a no-op, and cancellation, pointer capture, board boundary and recorder semantics remain unchanged. The UI now explains the gesture at the board. New Playwright regression reproduces long press with Conveyor tool selected and checks orientation persistence after reload. The existing scaled-board test was updated to reflect the intentional new contract, rather than weakening coverage.

Human retest remains necessary. Long-press meaning here is press then drag, not tap-and-hold without pointer movement.
