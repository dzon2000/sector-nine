# v0.2 Implementation Plan

Status: planning; implementation and validation pending.
Baseline: develop. Specification: docs/specifications/v0.2.md. Decision: ADR-0002.

## Architecture review (v0.1)
- `src/domain/model.ts` uses a two-item union, scalar `oreInput`, and schema v1; introduce typed recipe definitions, per-material bounded inventories, technology state and v2 schema without changing approved prices.
- `src/simulation/engine.ts` hardcodes iron-mine/furnace behavior and one furnace input; generalize production with atomic multi-input reservation and deterministic completion, preserving transfer snapshot, round-robin arbitration and backpressure.
- `src/game/commands.ts` validates iron-only deposits and lacks unlock purchases; add coal placement, furnace milestone gate and technology commands with separate capital ledger.
- `src/game/missions.ts` ends at DONE; append sequential M5–M7 using terminal sales counters, narrative and contextual tutorial.
- `src/persistence/indexedDb.ts` validates only schema v1; add explicit validated v1→v2 migration preserving cycles, entities, balances, counters and IndexedDB database identity.
- `src/ui/App.tsx` and `src/rendering/Board.tsx` consume old entity shape; adapt only after headless tests pass.
- Preserve existing `tests/integration/reference.test.ts`, `tests/integration/acceptance.test.ts`, `tests/unit/engine.test.ts` and Playwright onboarding/persistence tests.

## Execution gates
1. Freeze constants from approved specification and record baseline reference results.
2. Implement WP1 migration and typed domain; validate real v1 fixtures, including occupied coal deposits and in-progress cycles.
3. Implement WP2 engine without React/DOM/persistence dependencies.
4. Complete WP3 headless tests and economic reports; retain 30 ore / 15 ingots / 58.50 Cr reference window. If balance fails, report discrepancy and request design review; never silently retune constants.
5. Implement WP4 purchase commands and persistence tests, then WP5 UI/tutorial/story.
6. Execute WP6: `npm ci`, `npm run build`, `npm test`, `npm run test:e2e`; capture exact results and evidence for all 24 ACs before opening a non-draft release PR.

## Constraints
No power, offline production, splitters, labs, research timers, map expansion, or unapproved economy changes. Never overwrite a corrupt or un-migratable save. Do not merge PR.
