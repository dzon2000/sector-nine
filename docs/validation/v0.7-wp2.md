Cash and operating profit are distinct. Revenue and operating cost remain in the Inspector's operating account. The clock keeps keyboard-accessible 1×/2× and Run/Pause; site power appears when it has a recorded state. The palette groups the released sprites by use, shows cost and lock status, and repeats the selected tool beside the map. The Inspector shows latest blockage with text and a symbol, routing and other machine inputs, outputs, and diagnostics. The **Menu** holds help, keyboard shortcuts, campaign reset, recorder access, and font licenses.

The active Operations Console shows mission ID, objective, measured progress, and first unmet requirement where applicable. **Briefing** explains the window or stage. **Archive** lists unlocked messages, including the Chapter IV request and its final reply. Typical play and chapter-entry actions remain available. Briefing and archive never pause or advance the clock on their own. Keyboard close returns focus, including Help and Foundry replay launched from Menu. The compact footer exposes the WP1 session controls.

Desktop at both review sizes displays the full 528 × 528 CSS-pixel canvas. The compact frame fits the whole canvas, keeping the original 528-unit backing geometry and artwork. The 1024 × 576 CSS viewport check represents the layout space from 1280 × 720 at 125% zoom. Exact border-to-tile hit-testing and map overlays are WP3.

## Reproduce

Run `npm ci`, `npx playwright install chromium`, then:

```sh
SECTOR9_WP2_CAPTURE_DIR=/tmp/sektor9-wp2-review npm run test:e2e -- tests/e2e/v0.7-operations-hud.spec.ts
```

The capture test starts the normal game at M1 and chooses a paid Corporate playtest from the built-in selector for M15. It advances the simulation from the M13 handoff, rotates the conveyor at (1, 7) east after reaching M15, then advances 60 ticks. At tick 2167 it verifies the paused blocker, 2/2 power and 573.65 Cr operating profit. These images are automated browser captures.
