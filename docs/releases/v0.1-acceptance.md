## 3. Defect found during acceptance

The initial engine implementation incorrectly rejected moving an item into an occupied conveyor cell even when the previous item left that cell in the same tick. The stricter atomic-transfer acceptance test failed, exposing this behavior. Fixed in commit `4aa248c` (`fix: resolve atomic conveyor departures by source dependency`). The subsequent CI run passed all 29 Vitest tests and the browser E2E check.

## 4. Product decisions deferred

The v0.1 economy and construction rules remain unchanged: **300 Cr starting budget** and the **furnace available immediately**. Future scope: retain 300 Cr but unlock the furnace after completion of M2 (First Delivery), so new players first learn raw-ore delivery. This is a proposed follow-up **outside v0.1**, requiring an approved specification/decision before implementation.
