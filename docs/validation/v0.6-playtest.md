# v0.6 human playtest

## Early game

Start fresh, opt in to recording and retain the exact build identifier. Run M1 at 1×, then try 2× during an uninterrupted production window. Pause and resume at 2×. Switch back to 1× while placing and rotating a machine. Record the tick and wall-clock boundaries for a representative uninterrupted segment at each speed. In a 60-tick segment, expected ideal active times are 60 and 30 seconds, respectively.

Mark waiting for credits, waiting for mission/stability, and planning with the existing recorder controls. Note story-reading intervals separately in the playtest notes. Record where the speed selector helped, where inputs felt rushed and whether mission targets were understandable. Report elapsed session time separately from active simulation time.

## Sprite recognition

At default board size and one supported scaled viewport, watch a congested line at both speeds. Identify iron ore vs copper ore, coal vs gear, iron ingot vs steel, and occupied vs empty conveyor cells. Rotate a splitter through its four orientations, select and rotate a producer in one pointer action, and check that exposed and occupied copper/silicon deposits remain readable. Note any confusion with coordinates, direction and speed.

## Chapter IV after rule approval and integration

Use a paid M13 checkpoint to test the next chapter without replaying earlier chapters during each iteration. Record route, line changes, deletions, replacements, capital spend and elapsed time. Inspect continuity and identify the starving branch before changing a routing setting. Verify an interrupted run can recover. Reload an active mission, hear the station reply, and return to free play. Preserve a fresh-campaign run as separate regression evidence. Record the owner's acceptance independently of automated QA.
