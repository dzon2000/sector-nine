The released desktop UI shows revenue and operating cost alongside profit in the top bar. Compact mode hides both side panels, so readers must open the palette to check the selected build tool and the inspector to see the stalled belt. The proposed top bar gives cash and operating profit distinct positions, the map summary keeps the selected tool visible, and the console separates its active objective from briefing and archive. The compact map and inspector button both identify the blockage with words and a symbol.

## Reproduce

From the repository root, use Node 24 and Playwright Chromium.

```sh
npm ci
npx playwright install chromium
node scripts/capture-v07-wp0.mjs /tmp/sector-nine-v07-captures
```

Set `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` when using an alternative compatible Chromium binary. The capture script runs the existing paid checkpoint exporter and validates both fixtures. It launches a fresh browser context for each capture and seeds only that context's temporary local game slot. It verifies both fonts are loaded, checks horizontal overflow and verifies that the board and active stage are both visible at each review size, and tests keyboard entry and focus return for the briefing. It also checks a 1024 × 576 CSS viewport as a layout approximation of 1280 × 720 at 125% browser zoom. Native browser zoom, live placement and rotation, and gameplay at both speeds are subsequent work. The Run and speed renderings are illustrative. The font files and their licenses apply to the mockup only.
