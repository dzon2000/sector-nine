# Launch a paid post-M13 playtest

From the repository checkout for the build under review, install project dependencies and Playwright Chromium once.

```sh
npm ci
npx playwright install chromium
```

Start a disposable local playtest with either completed M12 route.

```sh
node scripts/play-post-m13.mjs independent
node scripts/play-post-m13.mjs corporate
```

The launcher replays the paid campaign from 300 Cr through M13, validates the current save, and loads the selected endpoint in a separate Chromium window. The factory opens paused so the player can inspect resources, layout and Chapter IV availability at the original checkpoint. Select **Run** when ready. Close the playtest page to end the session. Relaunch to return to the original checkpoint.

The launcher uses a fresh browser context and temporary export files. The isolated save and opt-in recorder session last until that browser closes. Export any playtest report before closing the window. This launcher is intended for developer and Product Owner validation from source.

Add `--verify` after the route to open headlessly and check that the application restores the paused checkpoint at the exported tick.
