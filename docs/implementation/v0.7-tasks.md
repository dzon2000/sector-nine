## Technical handoff

- Scope persistence queues, load generation, restart and epoch by explicit session storage slot. Capture slot and epoch when enqueueing. Keep existing campaign keys. Cancel or reject a checkpoint launch before replacing storage when validation fails. Ensure unmounted sessions and stale writes cannot change a different slot. Cover queue behavior in `tests/integration/v0.5-save-queue.test.ts` or an equivalent focused integration test.
- Bind the app clock, recorder and save operations to one session per mount or use equivalent lifecycle guards. Keep collection opt-in and retain provenance. Record chapter origin, route, fixture and starting tick independently of the campaign mission identifiers. The existing recorder identifies M1–M10 and tracks Chapter III transitions separately. Add typed Chapter V transitions instead of widening old IDs by casting.
- Start UI regressions with the current chapter-controls, board, clock and Chapter IV browser tests. Keep programmatic labels, focus return and map sizing usable at browser zoom. Test selection and color-independent status on a congested line.
- Chapter V feasibility uses existing physical production and terminal sales observations. Both paid v0.6 reference factories reached a similar gears-and-circuits objective early during the earlier probes. Test untouched snapshots, then test drained buffers, one-sided failures and bounded edits before choosing M17 targets. Keep an intentionally prepared factory eligible.
- Reuse the existing archive flow where practical. Chapter V may echo the earlier sealed Sublevel 03 reference. The draft leaves the link between that sender and the downstream seal unresolved.
- After freeze, evaluate mission progress from authoritative engine tick events at the same boundary as Chapter IV. Prove equal results from commands issued at equal tick boundaries. Separate player elapsed wall time from engine timing.

Ship WP0 as review evidence. Subsequent functional changes follow red, green and refactor and retain their explicit work-package gates.
